Slowth hides Shorts and Reels on YouTube, Instagram, Facebook, and X — and blocks TikTok entirely. Per-site control. Strict mode for the days you don’t trust yourself. No accounts. No tracking.

What it does

  • YouTube, Instagram, Facebook, X — three modes per site: off, hide Shorts/Reels only, or block the whole site.
  • TikTok — block the entire site (there’s nothing else there).
  • Strict mode — 24h lock. Once on, settings can’t be changed early. Survives restart.
  • Remote rules — selectors update every 6h from a public GitHub Gist. No server, no telemetry.

How it works

Slowth runs as a Safari Web Extension on iOS and macOS, plus a small host app for settings. Blocking happens in your browser — nothing about your activity leaves the device. Rules (which CSS selectors to hide, which URLs to redirect) are pulled from a public list on GitHub. That’s the entire stack.
