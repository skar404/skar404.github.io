Getting started

Enable Slowth in Safari (iOS)

  1. Open Settings → Apps → Safari → Extensions.
  2. Tap Slowth and turn it on.
  3. Tap All Websites → Allow.
  4. Open YouTube/Instagram/etc. — Shorts and Reels are gone.

Enable Slowth in Safari (macOS)

  1. Open Safari → Settings → Extensions.
  2. Check the box next to Slowth.
  3. If prompted, click Always Allow on Every Website.

FAQ

What does each per-site mode do?
Off — Slowth does nothing for that site. Block shorts — hides the Shorts/Reels feed and removes the tab from navigation. Block site — redirects the whole domain to a blocked page. TikTok only has Off / Block site (everything on TikTok is short video).
What is Strict Mode?
A 24-hour lock. While Strict Mode is on you can’t change any toggle, disable Strict Mode early, or refresh the rule list. It survives app restart and reboot. The only way out is to wait — or uninstall. Use it when you know future-you will try to negotiate.
Does Slowth see my browsing?
No. Filtering runs entirely in your browser. Slowth never sends URLs, page content, or any other activity off your device. See the privacy policy.
What are these “rules” that update every 6 hours?
A list of CSS selectors and URL patterns saying “this element on YouTube is the Shorts shelf.” Sites change their HTML constantly, so the list is hosted on a public GitHub Gist and Slowth pulls the latest version every 6 hours. The list contains no personal data. You can inspect it on GitHub.
App blocking on iOS — what is that?
On iOS, Slowth uses Apple’s Family Controls framework to block native apps you pick (TikTok, Instagram, etc). Selection happens through Apple’s system picker. Your selection stays on-device. Slowth never sees which apps you chose.
Why doesn’t YouTube look right after I install Slowth?
Refresh the page. Safari may have cached the pre-extension version. If a new layout slips through, tap Update rules now in the app, then refresh.
I disabled Strict Mode but settings are still locked.
Strict Mode runs to a date stored in shared storage. Even closing/reopening the app doesn’t end it early — that’s the point. It will release automatically when the timer hits 0.
