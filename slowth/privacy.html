Privacy Policy

Last updated: 28 April 2026

Slowth doesn’t collect, store, or transmit any personal data. There is no account, no analytics, no tracking, no advertising SDK, and no server that knows you exist. This page is the long version of that.

What Slowth does on your device

Slowth is a Safari Web Extension and a small host app. It hides Shorts/Reels feeds and can redirect short-video sites. All of that filtering runs locally in Safari. URLs, page content, and your activity never leave your device.

What we store, and where

  • Your settings (per-site mode, Strict Mode timer, app-blocking selection) are saved in a shared App Group container on your device. They never sync to us.
  • The blocking rule list (CSS selectors and URL patterns) is cached on your device after it’s downloaded. The list contains no personal data — it’s the same list everyone gets.

What leaves your device

Exactly one network request: every six hours, the app fetches the latest blocking-rule list from a public GitHub Gist over HTTPS. The request includes only what any normal HTTPS fetch includes (your IP address, which GitHub sees the same way it would for any visitor). No identifiers, no telemetry payload, no analytics ping.

GitHub’s own privacy policy applies to that fetch: github.com/privacy.

Family Controls (iOS only)

On iOS, Slowth uses Apple’s Family Controls framework to optionally block native apps you choose. The list of apps you select is stored by iOS in a privacy-protected token; the OS will not reveal which apps you picked, even to Slowth. Slowth only stores the opaque token locally and asks iOS to enforce the shield.

Third-party services

  • GitHub — hosts the public blocking-rule list. Slowth fetches the file; nothing else.
  • That’s the entire list.

Children

Slowth doesn’t collect data from anyone, including children. The app is safe for users of any age.

Changes

If this policy changes, the “Last updated” date at the top will change. Material changes will also be noted in app release notes.
